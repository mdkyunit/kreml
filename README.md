# kreml
A terminal based nuclear war simulator. Will use scientific calculations of factors such as fallout to calculate fatalities in order to create a chillingly immersive nuclear war sim.
# Features (Planned)
1. All countries that had nuclear weapons during the cold war, circa 1984 will be playable including the United States, USSR, United Kingdom, France, and china. Time period subject to change.
2. An as realistic-- but still videogame-y terminal interface for controlling your nuclear arsenal using terminal inputs. Think of "War Games".
3. Other countries will be computer controlled, reacting to your decisions. However, I want to use rng to ensure every time you play it is different.
4. Multi threading??? Possible. I don't want the game world to stop while you are deciding what input to do next. The scale of time in this game is undecided. I cant even think of how to begin to implement a time keeping system. However i feel like 1 day per minute for decisions to occur seems reasonable.
